# ますレッスン ノベルゲーム（mlc-novels）

数学・数理ITの「意味が分からない」を、物語と体験を通して解消する、ますレッスンのノベルゲーム開発プロジェクトです。

## 1. プロジェクトについて

数学や数理ITを、単に公式や計算方法を覚えるものではなく、自分で考え、発見し、日常や人生とつなげる学びにすることを目指しています。

物語・キャラクター・選択肢・画像・音声などを組み合わせ、プレイヤーが楽しみながら「なぜ？」を発見できる学習体験を制作します。

## 2. 開発方針

- 数学や数理ITの考え方を、物語と体験を通して伝える
- ゲームごとのストーリーと、共通のゲームエンジンを分離する
- キャラクター・背景・音声などの素材を共通管理する
- 設定を集約し、ゲームの追加・修正をしやすくする
- GitHubでソースコードと変更履歴を管理する
- 公開先の環境に依存しすぎない構成を目指す

## 3. フォルダ構成

```text
mlc-novels/
├── index.html          # ゲームの入口
├── assets/             # 共通素材
│   ├── bg/             # 背景画像
│   ├── bgm/            # BGM・音声
│   └── chara/          # キャラクター画像
├── config/
│   └── novel-config.js # 共通設定
├── core/               # 共通エンジン・スタイル
│   ├── common-loader.js
│   ├── novel-engine.js
│   ├── novel-engine-mobile.js
│   ├── novel-style.css
│   └── novel-style-mobile.css
├── games/              # ゲームごとのファイル
│   ├── tutorial/       # チュートリアル
│   └── 10_excel/       # Excel・家計簿ゲーム
└── popup-data/         # ポップアップ用データ
```

※実際のフォルダ・ファイルは開発に応じて追加・変更します。

## 4. 主な構成要素

| 要素 | 役割 |
|---|---|
| `config/` | キャラクター・背景・音声などの共通設定 |
| `core/` | PC版・スマホ版のゲームエンジンと表示スタイル |
| `games/` | 各ゲームのHTML・ストーリー・画像 |
| `assets/` | 複数のゲームで使用する素材 |
| `popup-data/` | ポップアップで表示するデータ |

## 6. Gitによるバージョン管理

GitHubリポジトリ：

https://github.com/hsoplusmath-sudo/mlc-novels

- ブランチ：`main`
- 初期保存版タグ：`v1.0.0`

### 基本ルール

1. ファイルを編集する
2. 変更内容を確認する
3. コミットメッセージを記録する
4. GitHubへPushする
5. 大きな節目でタグを付け、保存版を記録する

コミットメッセージは、後から変更内容を把握できるよう、日本語で具体的に記録します。
